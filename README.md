## 🚀 On the workbench: LaunchDesk

> **A better first day starts with a better process.**

LaunchDesk brings employee onboarding into one place — **tasks, documents,
checklists, and progress**, all managed from a single dashboard.

Scattered documents and repetitive tasks make onboarding harder than it needs
to be. I'm building LaunchDesk to give HR teams a clear, structured process
and help every new hire get off to the best possible start.

| For HR teams | For new employees |
| :--- | :--- |
| Organize tasks, documents, and checklists | Follow a clear path from day one |
| Track progress across the onboarding process | Find onboarding materials in one place |
| Deliver a consistent onboarding experience | Know what to do next |

<sub>ONE DASHBOARD · A CLEAR PROCESS · A STRONGER START</sub>
